# Tectonic

Harita sahibinin çizdiği siyah beyaz kıyı maskesinden inandırıcı bir dünya (tektonik tarih, topografya) kurup Merak'a
(merakmapmaker.com) hazır yükseklik haritası üreten proje.

- `CLAUDE.md`: çalışma biçimi, sahibin tercihleri, yöntem, Merak ölçümleri, dersler.
- `maskeden-merak/`: haritadan bağımsız araç takımı (Python). Başlangıç: `maskeden-merak/README.md`, aşama aşama yol: `maskeden-merak/YOL.md`.
- `belgeler/ilk_dunya/`: ilk dünyada izlenen yol ve ölçümler.

İlk dünyanın kodu ve verisi `athinker24/Merakproject` deposunda.
